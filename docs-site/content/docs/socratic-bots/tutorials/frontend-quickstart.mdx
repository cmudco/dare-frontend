At the end you have the web app running on &lt;http://localhost:5174&gt; against your local backends, in
about five minutes. To deploy it, see [docs/how-to/deploy.md](/docs/socratic-bots/how-to/deploy-frontend).

This guide covers the frontend only. The app needs the Socratic Bots backend and DARE behind it. If
those are not running yet, start with the
[full-stack quick start](https://github.com/cmudco/socraticbots-backend/blob/dev/docs/tutorials/quickstart.md),
which brings up all the services in order and ends by pointing back here.

## Prerequisites

- **Node.js 20+** (Vitest 4 needs it; the team uses Node 22) and **npm 10+**, which ships with it.
  Or Docker, to run the production build instead of the dev server (step 3, Option B).
- **Socratic Bots backend** running on `http://localhost:8001`.
- **DARE backend** running on `http://localhost:8000`, with Redis for Socket.IO.
- **voice-agent-runtime** (optional), only for voice exams with the Mistral/Pipecat voice.

## 1. Install

`npm ci` installs exactly what `package-lock.json` pins, and installs the Husky pre-commit hook.

```bash
git clone https://github.com/cmudco/socraticbots-frontend.git
cd socraticbots-frontend
npm ci
```

## 2. Configure

The defaults in `.env.example` point at the standard local ports, so you usually change nothing.

```bash
cp .env.example .env
```

| Variable                 | Default                     | Points at                                |
| ------------------------ | --------------------------- | ---------------------------------------- |
| `VITE_API_URL`           | `http://localhost:8001/api` | Socratic Bots backend REST API           |
| `VITE_DARE_SOCKET_URL`   | `http://localhost:8000`     | DARE backend, for chat over Socket.IO    |
| `VITE_DARE_FRONTEND_URL` | `http://localhost:5173`     | DARE web app, for billing hand-off links |

Every variable, including the optional Sentry ones, is in
[docs/reference/configuration.md](/docs/socratic-bots/reference/frontend-configuration). `VITE_*` values are compiled into
the browser bundle: never put secrets in them.

## 3. Run

Use port 5174 either way. Vite's default, 5173, is where the DARE frontend runs, and DARE tells the
two apps apart by their origin. The Socratic Bots backend allows `http://localhost:5174` for CORS
out of the box.

### Option A — dev server

```bash
npm run dev -- --port 5174
```

Open &lt;http://localhost:5174&gt;. Vite hot-reloads on save.

### Option B — Docker

This builds the production bundle and serves it with nginx; there is no hot reload. The image does
not read `.env`: it bakes in the same local defaults, and you override them with `--build-arg`
(see [docs/how-to/deploy.md](/docs/socratic-bots/how-to/deploy-frontend#docker)).

```bash
docker build -t socraticbots-frontend .
docker run -d --name socraticbots-frontend -p 5174:80 socraticbots-frontend
```

Open &lt;http://localhost:5174&gt;. Rebuild the image to pick up code changes.

## 4. Sign in

Accounts live in DARE. You have three ways in:

- **Log in with an existing DARE account** on `/login`. The Socratic Bots backend creates its
  local copy of the user on first login.
- **Register** on `/register` with an access code. The code is an access code group created in the
  DARE admin (`http://localhost:8000/admin/`). The group's default role decides whether the new
  account is a student or a creator.
- **Use the DARE superuser** you created while setting up DARE.

Building tutors needs a creator role (`CREATOR`, `RESEARCHER`, `SUPERVISOR` or `SUPERADMIN`). Set
`platform_role` on the user in the DARE admin if your account sees only the student views.

## Verify

1. After login you land on **Home**. The sidebar shows Subscription Codes, Chatbot Groups, Chat,
   Voice Assignments and Settings; creators also see **Bot Access**.
2. As a creator, open **Chatbot Groups**, create a group and a bot, pick a model, and save.
3. Open the bot in **Chat** and send a message. A streaming reply means the Socket.IO connection to
   DARE works and DARE has a working model and wallet.

## Scripts

Run the checks (`lint`, `format:check`, `test`, `test:voice-contract`, `build`) before you commit.

| Command                       | What it does                                        |
| ----------------------------- | --------------------------------------------------- |
| `npm run dev`                 | Vite dev server (pass `-- --port 5174`)             |
| `npm run build`               | Type-check (`tsc -b`) and build to `dist/`          |
| `npm run preview`             | Serve `dist/` locally                               |
| `npm run lint` / `lint:fix`   | ESLint                                              |
| `npm run format:check`        | Prettier check                                      |
| `npm run format`              | Prettier over the whole repo; do not use it on a PR |
| `npm test`                    | Vitest unit tests                                   |
| `npm run test:voice`          | Voice session and feedback tests only               |
| `npm run test:voice-contract` | Type-check and test the voice API contract          |

## Troubleshooting

- **Every request fails with a network or CORS error.** The Socratic Bots backend is not on
  `:8001`, or the app is not on `:5174`. Check `VITE_API_URL` and the port you started Vite on.
- **Login succeeds but you are bounced back to `/login`.** The Socratic Bots backend cannot verify
  DARE's tokens. `SSO_JWT_KEY` must be set and identical in both backends; see the backend quick
  start.
- **Messages send but no reply streams.** The chat socket cannot reach DARE, or DARE cannot run
  the model. Check `VITE_DARE_SOCKET_URL`, that DARE runs under uvicorn (not `runserver`) with
  Redis up, and that DARE has a provider key.
- **Replies here look like DARE chats.** DARE identifies Socratic Bots by origin. DARE's
  `SOCRATIC_BOTS_FRONTEND_URL` must be `http://localhost:5174`.
- **A voice exam will not start.** Voice needs the voice runtime on `:8010` and
  `VOICE_RUNTIME_PUBLIC_URL` set on the Socratic Bots backend. See the voice-agent-runtime README.
- **You changed `.env` but nothing changed.** Vite reads `.env` at startup. Restart `npm run dev`.
- **`npm test` fails to start.** Node is older than 20. Run `node -v`.
